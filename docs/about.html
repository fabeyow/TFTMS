Developer

I designed and built the Tasks for Today Management System (TFTMS) as a laboratory activity to demonstrate full-stack web development using the CodeIgniter 4 framework with a MySQL database.

This application features four pages: a Welcome dashboard that highlights today's tasks, a complete Task List, a User Profile viewer, and this About page.
